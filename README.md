🦸 ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ GEROY v8.8

================================================================

📌 ЧТО ТАКОЕ GEROY?

GEROY - это лаунчер для обхода замедлений YouTube и других
сервисов. Он объединяет два инструмента (GoodbyeDPI и Zapret)
в одной программе с понятным интерфейсом.

Вам больше не нужно разбираться в .bat-файлах - просто
запустите GEROY и нажмите кнопку.

================================================================

📁 ЧТО НУЖНО ДЛЯ РАБОТЫ?

Перед запуском GEROY вам нужно подготовить файлы. (!!!если у вас только лаунчер!!!)

Есть два варианта:

ВАРИАНТ 1: GoodbyeDPI
------------------------------------
1. Создайте папку "goodbyeDPI" рядом с geroy.exe
2. Положите туда:
   ✅ goodbyedpi.exe
   ✅ WinDivert.dll
   ✅ WinDivert64.sys (или WinDivert32.sys)
   ✅ russia-blacklist.txt (или другой .txt список)

ВАРИАНТ 2: Zapret
----------------------------------------------------
 Создайте папку "zapret" и положите:
   ✅ winws.exe
   ✅ cygwin1.dll
   ✅ папку bin/ с .bin файлами
   ✅ папку lists/ с .txt списками

Где взять файлы?
- GoodbyeDPI: скачайте с официального репозитория
- Zapret: скачайте с официального репозитория
- вам они не понадобятся ведь файлы уже есть  
Если файлы лежат в другом месте - используйте кнопку
"Выбрать папку" в программе.

================================================================

🚀 ЗАПУСК GEROY

1. Запустите geroy.exe
2. Программа запросит права администратора - нажмите "Да"
   (без прав администратора обход НЕ работает!)

🖥️ ИНТЕРФЕЙС ПРОГРАММЫ

Главное окно состоит из нескольких блоков:

1. ЗАГОЛОВОК (вверху)
   - Название "ГЕРОЙ" и версия (8.8)

2. НАСТРОЙКИ (средняя часть)
   - Движок: выберите GoodbyeDPI или Zapret
   - DNS: выберите DNS-сервер (Google, Cloudflare, Яндекс, Quad9)
   - Стратегия: (только для Zapret) выберите способ обхода
   - TLS/QUIC: (только для Zapret) выберите .bin файлы

3. ПАНЕЛЬ УПРАВЛЕНИЯ
   - ▶ ЗАПУСТИТЬ - запустить обход
   - ⏹ ОСТАНОВИТЬ - остановить обход
   - 32/64-bit - переключить архитектуру
   - 📁 Выбрать папку - указать путь к файлам вручную

4. ЛОГ РАБОТЫ (внизу)
   - Показывает все действия и ошибки

5. СТАТУС-БАР (в самом низу)
   - Текущее состояние программы

================================================================

⚙️ НАСТРОЙКА ПЕРЕД ЗАПУСКОМ

ШАГ 1: Выберите движок
----------------------
Если у вас есть только GoodbyeDPI - выберите его.
Если есть Zapret - можете выбрать его для большего контроля.

Разница:
- GoodbyeDPI: проще, работает "из коробки"
- Zapret: больше настроек, может работать там, где GoodbyeDPI не справляется

ШАГ 2: Настройте DNS (для обоих движков)
----------------------------------------
Рекомендуемые DNS:
- Google (8.8.8.8) - самый быстрый
- Cloudflare (1.1.1.1) - хорошая альтернатива
- Яндекс (77.88.8.8) - может быть быстрее для России

ШАГ 3: Выберите стратегию (только для Zapret)
---------------------------------------------
Если один способ не работает - попробуйте другой.

Базовые:
- Стандартная (fake + ttl=8) - пробуйте первой

Продвинутые:
- Fake + wrong-seq
- Fake + reverse-frag
- Fake + wrong-chksum
- Fake + max-payload
- Fake + split
- Fake + disorder
- Fake + wssize
- Fake + all (максимальный обход)

ALT стратегии (ALT1-ALT12):
- Специальные комбинации параметров
- Работают у разных провайдеров
- Если стандартные не помогают - перебирайте ALT1-ALT12

ШАГ 4 (опционально): Кастомные параметры
----------------------------------------
Если ни одна стратегия не помогает, выберите "Fake + custom"
и введите свои параметры вручную.

Пример: --dpi-desync=fake --dpi-desync-ttl=8 --wrong-seq

================================================================

▶ ЗАПУСК И ОСТАНОВКА

ЗАПУСК:
1. Проверьте настройки
2. Нажмите ▶ ЗАПУСТИТЬ
3. В логе появится сообщение "Герой запущен!"
4. Статус изменится на "АКТИВЕН"

ОСТАНОВКА:
1. Нажмите ⏹ ОСТАНОВИТЬ
2. В логе появится сообщение "Герой остановлен"

================================================================

🔄 ПЕРЕКЛЮЧЕНИЕ 32/64-BIT

Если у вас 32-битная Windows, переключите на 32-bit.
По умолчанию стоит 64-bit.

Кнопка меняет цвет:
- Зелёная = 64-bit
- Жёлтая = 32-bit

ВАЖНО: драйвер WinDivert должен соответствовать вашей системе.

================================================================

📁 РУЧНОЙ ВЫБОР ФАЙЛОВ

Если автопоиск не сработал, можно указать файлы вручную:

1. Нажмите "Выбрать папку"
2. Найдите папку с файлами
3. Программа проверит наличие файлов

Или (в версиях 8.1+):
1. Нажмите на кнопку "📂" рядом с нужным файлом
2. Выберите файл вручную

Так можно указать:
- goodbyedpi.exe
- WinDivert.dll
- WinDivert.sys
- blacklist.txt
- winws.exe
- cygwin1.dll

================================================================

❌ ОШИБКИ И ИХ РЕШЕНИЕ

"Процесс завершился сразу после запуска"
→ Проверьте, что у вас есть права администратора
→ Проверьте, что все файлы на месте
→ Проверьте лог ошибок (error_log.txt)

"Не удаётся установить соединение с сайтом"
→ Проверьте интернет
→ Проверьте настройки брандмауэра
→ Попробуйте другой DNS

================================================================

💡 СОВЕТЫ

1. Всегда запускайте GEROY от имени администратора

2. Если YouTube не открывается:
   - Попробуйте другой движок
   - Попробуйте другую стратегию
   - Смените DNS

3. Если ничего не помогает:
   - Запустите ручной способ через .bat-файлы
   - .bat-файлы лежат в папках goodbyeDPI и zapret


4. Настройки сохраняются автоматически в config.json
   - Вы можете перенести этот файл на другой компьютер
   - Все настройки восстановятся
